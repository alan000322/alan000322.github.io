# Design Context

## Audience
Recruiters and hiring managers screening 何家慈 / Chia Tzu Ho. Each link is sent
for a specific application, so the URL (`?lang=` `?track=` `?photo=`) decides the
language, industry framing and photo. There is no on-page switcher.

## Use cases
- Read the resume in 30 seconds on desktop or phone.
- Print / save as an A4 PDF straight from the browser.
- Click an item's ↗ to reach a deeper page (write-up, photos, links).

## Personality
Plain, structured, confident. Strong ruled lines, a visible A4 sheet on desktop.
No numbered section labels (01 / 02), no decorative micro-captions.

| track   | palette                         | motion                  |
|---------|---------------------------------|-------------------------|
| tech    | black / white / grey            | fade only               |
| ai      | black / white / grey + blocks   | rules draw, counters    |
| media   | navy on newsprint, serif heads  | rules draw              |
| startup | navy ground, amber signal, free | hero rise, scroll reveal|

## Photo rules
- Default: no photo on every track.
- `lang=zh` can opt in with `photo=formal|talk`; `lang=en` never shows a photo.
- Photo present → asymmetric two columns. No photo → single column.
- Photos keep their original colour: crop and shape only, no filters or tints.
